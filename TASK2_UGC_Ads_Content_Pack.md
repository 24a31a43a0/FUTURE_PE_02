## 📋 Prompt Engineering Learnings

### Key Techniques Applied:
1. **Platform-specific prompting** — Different platforms need different tone/length/style. Specifying "Instagram Reels 45 seconds" vs "Facebook 60 seconds" changed outputs dramatically
2. **Persona-based audience definition** — "Indian college student, 20–23" produced more relatable content than just "young people"
3. **Tone anchoring** — "Sounds like a real person, NOT a salesman" consistently improved authenticity
4. **Format scaffolding** — Providing the [Hook → Problem → Solution → Proof → CTA] structure as part of the prompt ensured complete, conversion-optimized scripts
5. **Negative prompting** — "No bro-culture", "No artificial sweeteners mention in wrong context" helped avoid unwanted outputs

### Prompt Iteration Example:
- **V1:** "Write a UGC ad for protein powder" → Generic Western-sounding script, no Indian context
- **V2:** "Write UGC ad for Indian gym-goer" → Better, but still vague tone
- **V3:** Full structured prompt with persona + platform + format → Authentic, localized, conversion-ready ✅
